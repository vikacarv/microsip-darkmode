# MicroSIP Dark Mode Cyberpunk

> Versão modificada do MicroSIP 3.22.3 com tema Dark Mode completo em paleta Cyberpunk.

## ⚠️ Versão BETA

Esta é uma versão de testes. Podem existir bugs. Use com cautela em ambiente de produção.

## Screenshots

![MicroSIP Dark Mode](/dist/assets/screen_microsip.png)

## Funcionalidades do Dark Mode

- Janela principal com fundo escuro e abas customizadas
- Botão Chamar em rosa cyberpunk
- Sliders de volume em rosa
- Status bar escura com texto rosa
- Menus popup dark nativos (Windows 10 1903+)
- Todas as janelas filhas: Configurações, Conta, Ringin, Atalhos
- Listas de Registros e Contatos com header rosa

## Requisitos

- Windows 10 / 11
- Para dark mode completo: Windows 10 versão 1903 (build 18362) ou superior

## Instalação

1. Baixe `MicroSIP.exe` em [Releases](https://github.com/vikacarv/microsip-darkmode/releases)
2. Execute o arquivo — não requer instalação
3. Configure sua conta SIP normalmente
